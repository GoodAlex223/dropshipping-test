# Handoff: Mirox Shop — редизайн интернет-магазина

## Overview

Полный редизайн магазина одежды Mirox Shop (укр. локаль, ч/б премиум-эстетика уровня Represent / Fear of God): главная, каталог, карточка товара, корзина, checkout, контакты + мобильные версии ключевых экранов. Дизайн восстановлен с клиентского макета-изображения и согласован с владельцем.

## About the Design Files

Файлы `*.dc.html` в этом пакете — **дизайн-референсы, созданные в HTML** (прототипы, показывающие точный вид и поведение), а НЕ продакшен-код для копирования. Задача: **воссоздать эти экраны в существующем кодбейсе** `dropshipping` (Next.js 14 App Router + Tailwind + shadcn/ui) по его паттернам. Открой каждый `.dc.html` в браузере (нужны соседние `support.js`, `image-slot.js`, папка `images/`) и снимай точные значения из инлайн-стилей — они и есть спецификация.

## Fidelity

**High-fidelity.** Цвета, типографика, отступы, радиусы и интеракции финальные — воспроизводить пиксельно, но компонентами кодбейса (`Button`, `Card`, `RadioGroup` из shadcn/ui и т.д.).

## Interactions & Behavior

- Hover: ссылки #A3A3A3→#FFF; карточки — border #1A1A1A→#333; primary-кнопки #FFF→#E5E5E5; secondary — border #333→#666.
- Каталог: чип размера — toggle-фильтр (активный: белый фон, чёрный текст); сортировка — активная кнопка белая.
- Товар: выбор цвета (белый border 2px у активного свотча), размера (активный — белый фон); «ДОДАТИ В КОШИК» → состояние «✓ ДОДАНО В КОШИК»; подбор размера пересчитывается на input.
- Checkout: кликабельный степпер; radio-карточки доставки/оплаты (активная — border #FFF); поля карты скрываются при выборе «Оплата при отриманні».
- Корзина: qty min=1; удаление строки; суммы пересчитываются (uk-UA формат: «1 290 грн»).
- Hero-виньетка (главная): CSS-оверлей поверх фото, `pointer-events:none` — 4 линейных градиента (снизу сильный до 45%, сверху лёгкий 16%, бока до 20%). Фото сменное, эффект остаётся.

## State Management

- Корзина: существующий Zustand `src/stores/cart.store.ts` (не менять логику).
- Каталог: URL-параметры фильтров/сортировки (как сейчас в `products-content.tsx`).
- Товар: локальный стейт color/size/added; SizePicker: height/weight → размер (формула: XXL h≥190|w≥95; XL h≥184|w≥85; L h≥176|w≥72; M h≥168|w≥60; иначе S).
- Checkout: шаги information→shipping→payment (уже так); + выбор способа оплаты card|cod.

## Design Tokens

- Цвета: bg #000000; panel #0D0D0D; panel-2/border #1A1A1A; border-hover #333; text #FFF; secondary #A3A3A3; muted #737373; light #F5F5F5; статусные: stock #4ADE80, stars #FBBF24. Ярких цветов нет (требование клиента).
- Шрифт: Manrope 400–800 (в repo уже есть `--font-manrope`). Кнопки: 13px/800/tracking .06em/UPPERCASE.
- Радиусы: кнопки/инпуты 10px, карточки 14–16px, панели 20px, бейджи 99px. Отступы: страница 80px по бокам, секции 72px; grid gap 20px.
- Валюта: грн (UAH) — Stripe `currency: 'uah'`.

## Контентные ограничения (критично)

См. `mirox-design-spec.md` §4: «Безкоштовна доставка від 1000 грн» — НЕ добавлять (услуги нет); «Обмін розміру» — услуги пока нет, убрана; «Оплата при отриманні» подтверждена клиентом, в коде отсутствует — реализовать (TASK-049); claims 300+/100+ — client-supplied, не для structured data; новый seed одежды вместо электроники (§4 п.7).
