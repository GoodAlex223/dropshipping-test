# Mirox Shop — Design Spec (handoff для Claude Code)

Источник: изображение-макет клиента (`uploads/reference.png`) + кодбейс `dropshipping` (Next.js 14 App Router, Tailwind, shadcn/ui).
Референсы вёрстки (пиксельный источник правды): `Mirox Home.dc.html`, `Mirox Catalog.dc.html`, `Mirox Product.dc.html`, `Mirox Cart.dc.html`, `Mirox Checkout.dc.html`, `Mirox Contacts.dc.html`, `Mirox Mobile.dc.html` — открой их в браузере и копируй значения оттуда.

## 1. Дизайн-токены

Цвета (только монохром, без ярких цветов — требование клиента, client-brief list #1):

- `--bg: #000000` — фон страницы
- `--panel: #0D0D0D` — карточки/панели
- `--panel-2: #1A1A1A` — вторичные поверхности, бордеры-разделители
- `--border: #1A1A1A`, `--border-hover: #333333`
- `--text: #FFFFFF`, `--text-secondary: #A3A3A3`, `--text-muted: #737373`
- `--light: #F5F5F5` — светлые элементы (свотч «Білий»)
- Статусные исключения: наличие `#4ADE80`, рейтинг-звёзды `#FBBF24` (единственные не-монохромные акценты)

Типографика: Manrope (уже подключён в `src/app/layout.tsx` как `--font-manrope`), weights 400–800.

- H1 hero: 64px/1.05, 800, letter-spacing -0.02em; H1 страниц: 36–40px
- H2 секций: 28–32px 800; названия карточек: 14.5px 700; цены: 15px 800
- Body: 14–15px; вторичный текст: 12.5–13.5px; КНОПКИ: 13px 800, letter-spacing 0.06em, UPPERCASE

Геометрия: радиусы — карточки 16px, панели 20px, кнопки/инпуты 10px, бейджи pill (99px). Отступы страницы: 80px по бокам (desktop), секции 72px по вертикали. Grid товаров: 4 колонки, gap 20px (desktop); 2 колонки, gap 12px (mobile 390px).

Кнопки:

- Primary: белая (#FFF) на чёрном, чёрный текст, hover #E5E5E5
- Secondary: прозрачная, бордер #333, hover бордер #666
- Логотип: SVG из `src/components/common/Logo.tsx` (bag + M monogram) — использовать как есть.

## 2. Экраны

2. Hero: 2 колонки (текст слева / фото модели справа, 640px). Eyebrow «НОВА КОЛЕКЦІЯ» с тире-линией, H1 «СТИЛЬ. ЯКІСТЬ. ВПЕВНЕНІСТЬ.» (укр. локаль `home.hero.headline`), сабтайтл из `BRAND_HERO_SUBTITLE`, кнопки primary+secondary. Маппинг: `src/components/home/Hero.tsx` — использовать image-вариант layout (`home.hero.image`), нужен файл фото.
3. Benefit strip: 4 ячейки с 1px-сеткой (#1A1A1A gap-hack). Порядок: Швидка доставка (По всій Україні) / Преміум якість (Тільки найкращі матеріали) / Підтримка 24/7 (Ми завжди на зв'язку) / Оплата при отриманні (Без передоплати). Обновить `home.benefits` в `src/content/home.ts` под этот список (см. §4 п.2/2a).
4. Rail «Новинки»: 4 ProductCard. Маппинг: `src/components/home/ProductRail.tsx`, `src/components/products/ProductCard.tsx`.
5. «Чому обирають нас»: 2 колонки — слева заголовок + 2 stat-карточки (300+/100+ из `site.claims`, рендер только если не null), справа 6 пунктов из `home.whyChooseUs.items` (без «Обмін розміру») с белыми точками. Маппинг: `src/components/home/WhyChooseUs.tsx`.
6. Відгуки: 2 карточки (аватар-инициал, имя, звёзды, дата справа). Маппинг: `src/components/home/Testimonials.tsx`.
7. Footer: benefit-строка (тексты из `site.footerBenefits` — уже исправленные, см. §4) + соцсети из `site.socials` + копирайт-строка.

### Каталог (`src/app/(shop)/products/page.tsx`, `products-content.tsx`)

- Хлебные крошки, H1 40px, фильтр-бар: Фільтри, Ціна, Бренд, Розмір (чипы S–XXL, активный = белый фон), Колір, Наявність, справа Сортування (Новинки / Ціна ↑ / Ціна ↓).
- Grid 4×N ProductCard: фото, бейдж НОВИНКА (белый) или -15% (тёмный с бордером), имя, цена + зачёркнутая старая, строка размеров «S · M · L · XL». Пагинация: квадраты 36px.

### Товар (`src/app/(shop)/products/[slug]/product-detail-client.tsx`)

- 3 колонки: тумбнейлы 96px (вертикально, активный бордер #333→#FFF) / главное фото (радиус 20) / панель 420px.
- Панель: H1 30px, цена 26px, звёзды + «128 відгуків» (якорь на секцию отзывов), свотчи цвета (круг 36px, активный — белый бордер 2px), размеры S–XXL (кнопки 52px, активный белый), «Відкрити фото замірів» (secondary, иконка камеры), строка «● В наявності» (зелёный) + «Доставка Новою Поштою», ДОДАТИ В КОШИК (primary) / КУПИТИ В 1 КЛІК (secondary), «У вибране» + «Поділитися» (`SocialShareButtons.tsx`).
- Блок «Підбір розміру»: инпуты зріст/вага → рекомендация. Логика из референса: XXL если h≥190||w≥95; XL если h≥184||w≥85; L если h≥176||w≥72; M если h≥168||w≥60; иначе S. НОВЫЙ компонент (в кодбейсе нет) — предлагаемый путь `src/components/products/SizePicker.tsx`.

## 4. Контентные ограничения (ВАЖНО — не с картинки, а из кодбейса)

1. **НЕ добавлять «Безкоштовна доставка від 1000 грн»** — клиент подтвердил, что опции нет; в `site.ts` claim официально RETRACTED (нет реализующей логики в `calculateOrderTotals()`). На макете-картинке она есть — игнорировать.
2. **«Оплата при отриманні» подтверждена клиентом (26.07.2026)** — присутствует в дизайне (benefit strip, footer, checkout шаг 3, «Без передоплати»). В коде метода ещё нет — реализация обязательна = TASK-049.
   2a. **Услуги «Обмін розміру» пока НЕТ** (клиент, 26.07.2026) — убрана из всех бенефитов и списков; в `home.ts` benefits и `site.ts` footerBenefits заменить на «Оплата при отриманні»; блок на Контактах — только «Повернення» (14 днів).
3. Claims «300+ OLX» / «100+ Instagram» — client-supplied, unaudited (`site.claims`); рендерить только их, НЕ придумывать рейтинги; никогда не отдавать в aggregateRating structured data.
4. Соцсети: placeholder-хендлы `@miroxshop` до подтверждения клиентом.
5. «14 днів на повернення» — не противоречит коду, но не подтверждено клиентом (см. комментарий в `site.ts`).
6. Валюта: грн (UAH). Кодбейс сейчас в USD (Stripe) — конверсия валюты входит в объём работ (Stripe currency: 'uah').
7. Seed-товары в `prisma/seed-data/products.ts` — электроника; нужен новый seed с одеждой Mirox (названия/цены в референсах: Худі Mirox Basic 1290, Футболка Mirox 590/690, Олімпійка 1490, Худі White 1290, Кепка 490, …).
